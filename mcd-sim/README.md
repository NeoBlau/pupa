# МЦД Симулятор

Железнодорожный симулятор Московских центральных диаметров (D1–D4) на three.js. Запускается в браузере (Chrome/Edge/Firefox с WebGL2), поддерживает клавиатуру, мышь и геймпад.

## Запуск

```bash
cd mcd-sim
npm install
npm run dev          # http://localhost:5173
# или сборка: npm run build && npm run preview
```

Ассеты Poly Haven, модели людей и объявления уже лежат в `public/assets`. Повторно скачать/пересобрать:

```bash
npm run assets                                   # Poly Haven (CC0) + люди three.js
node tools/decimate.mjs in.glb out.glb 22000 3000 # облегчение фотограмметрических деревьев
python3 tools/gen_announcements.py <piper> <voices>  # объявления Piper TTS
python3 tools/geocode.py && python3 tools/build_lines.py  # координаты станций из OSM
```

### Ассеты Sketchfab

Лучшие готовые модели МЦД-подвижного состава лежат на Sketchfab (CC-BY): «Ласточка» ЭС2Г, пульт Desiro «Ласточка», ЭД4М, «Иволга», панельные дома, турникеты, мост. Список — `tools/sketchfab-models.json`. Скачивание требует API-токена (https://sketchfab.com/settings/password → API Token):

```bash
SKETCHFAB_TOKEN=xxxx npm run assets:sketchfab
```

Скрипт оптимизирует модели (WebP-текстуры ≤2048) и пишет `public/assets/sketchfab/manifest.json`. Игра сама использует скачанные модели вместо запасных: внешний вид состава, пульт кабины, жилые дома, турникеты. Модели нормализуются автоматически (длинная ось → вдоль пути, масштаб по длине вагона). Если модель — целый 5-вагонный состав, она ставится секциями; если один головной вагон — только на головные, промежуточные остаются запасными. Положение камеры в кабине у внешнего пульта подбирается по габаритам и может потребовать ручной правки (`src/train/cab.js`).

## Что реализовано

- **Режимы**: по расписанию (выбор линии, поезда, направления, рейса и участка; оценка пунктуальности, точности остановки, комфорта, безопасности) и свободный (станция, направление, время; оборот на конечной со сменой кабины).
- **Линии**: D1 (25 станций), D2 (37), D3 (40), D4 (35). Порядок станций — по схеме МЦД; координаты — OpenStreetMap; станции без надёжных координат помечены в меню «прибл.».
- **Поезда**: ЭС2Г «Ласточка» (5/10 ваг.), ЭГ2Тв «Иволга» (7/11), ЭД4М (10/11) — разные масса, мощность, сила тяги, замедление, тип тормоза (рекуперация / только пневматика с задержкой), орган управления (единая рукоятка / КМ + кран №395), звук двигателя и дверей.
- **Физика**: сила тяги с ограничением по мощности, ограничение рывка, основное сопротивление (формула вида w0 = a + bv + cv²), уклоны, кривые, масса с учётом вращающихся масс, давление в ТЦ/ТМ/ГР, компрессор, блокировка тяги при открытых дверях.
- **Безопасность**: автоблокировка (блок-участки, светофоры зелёный/жёлтый/красный, занятость реальными и виртуальными поездами), выходные сигналы, открывающиеся по расписанию, модель КЛУБ (допустимая скорость, кривая торможения, принудительное торможение), АЛСН (З/Ж/КЖ/Б), бдительность, проезд красного проходного после стоянки со скоростью ≤20 км/ч, фиксация проезда запрещающего.
- **Мир**: рельсы Р65, шпалы Ш1 (инстансинг), балластная призма, грунт с рельефом, контактная сеть (опоры, консоли, изоляторы, зигзаг, струны), светофоры, знаки скорости, километровые столбы, станции (высокие платформы, тактильная полоса, навесы, табло отправления с живым расписанием, часы, таблички, скамейки, урны, фонари, камеры, надземный или подземный переход, павильон с турникетами и билетными автоматами), лес (импостеры для дальних деревьев), бетонные заборы ПО-2, шумозащитные экраны, сетчатые ограждения, жилая застройка, автомобили.
- **Окружение**: динамическое небо, реальное положение солнца для Москвы по сезону и времени, облака, звёзды, туман, дождь, снег, зимние текстуры, ночное освещение станций и окон домов.
- **Люди и трафик**: пассажиры на платформах (анимации), посадка в открытые двери; попутные и встречные поезда по расписанию с автоведением.
- **Звук**: тяговые двигатели (асинхронный «поющий» / коллекторный), качение, стыки, тормоза, скрип при остановке, компрессор, двери, тифон, сигналы КЛУБ, ветер, дождь, город, птицы; объявления на русском (мужской голос к центру, женский от центра — по аналогии с метро, приблизительно).
- **Камеры**: кабина с обзором, внешняя орбита, у пути, пешком — выход из кабины, проход по салону, выход в открытую дверь на платформу, подъём на переходы.

## Известные пробелы (честно)

- Без токена Sketchfab **поезда, кабина и дома — запасные процедурные модели** (кузов по сечению, ливрея на canvas, окна, двери, тележки, токоприёмник). Это не уровень Train Sim World. Контактная сеть, платформы, навесы, светофоры — собственная геометрия с PBR-текстурами: готовых моделей российской инфраструктуры в свободном доступе почти нет.
- Ось пути между станциями — сплайн через координаты станций, а не реальная геометрия пути из OSM (Overpass был недоступен). Профиль, ограничения скорости, сигналы, тип платформ, стрелки и расписание — сгенерированы и приблизительны.
- Центральный участок МЦД-4 (Москва-Сити — Белорусская — Савёловская — Рижская) и ряд пересадок — приблизительно; часть названий станций может не совпадать с текущими.
- Стрелочные переводы и депо пока не смоделированы, оборот на конечной выполняется условным съездом.
- Голос объявлений синтезирован (Piper), ударения иногда неверны.
