# Компас — навигатор

Веб-приложение (PWA): офлайн и онлайн навигация, радар-детектор камер, погода
в пути и пешие маршруты по живописным тропам. Без сборки, без зависимостей,
без API-ключей — открывается с любого статик-хостинга и ставится на телефон
как обычное приложение.

## Запуск

```bash
node serve.mjs 8080        # либо python3 -m http.server 8080
```

Откройте `http://localhost:8080/`. ES-модули и service worker требуют
`http(s)` — с `file://` приложение не заработает.

Для установки на телефон и работы офлайн нужен HTTPS: подойдёт любой хостинг
статики. Готовые команды — в [`DEPLOY.md`](DEPLOY.md), короткий вариант:

```bash
cd navigator && npx vercel --prod
```

MapLibre лежит в `vendor/`, но если папку не скопировать, он подхватится с
cdnjs — приложение не покажет пустой экран ни в одном из случаев.

## Что внутри

| | |
|---|---|
| Карта | MapLibre GL (в `vendor/`, локально) |
| Тайлы | CARTO Voyager / Dark Matter, Esri World Imagery, OpenTopoMap |
| Онлайн-маршруты | OSRM |
| Офлайн-маршруты | собственный движок: граф из OSM + A\* (`js/routing/`) |
| Геокодер | Photon и Nominatim онлайн, свой индекс офлайн |
| Данные OSM | Overpass API (три зеркала с ротацией) |
| Погода | Open-Meteo, осадки — RainViewer |
| Пробки | опционально, по вашему ключу TomTom |
| Высоты | Open-Meteo Elevation |

Ключи не нужны ни для чего. Всё хранится в IndexedDB и Cache Storage.

## Офлайн

Это не «кэш последних просмотренных тайлов». Пакет региона содержит:

* тайлы карты в выбранном диапазоне зумов (день + ночь);
* **дорожный граф** — по нему строится настоящий маршрут без сети;
* камеры;
* тропы и видовые точки;
* адреса и места для поиска.

Граф упакован в типизированные массивы: координаты — int32 с шагом 1e-7°
(≈1 см), рёбра сжаты между перекрёстками, смежность в CSR. Город на ~120 тысяч
рёбер занимает единицы мегабайт и снапится к дороге за доли миллисекунды.

Маршрутизатор — A\* с эвристикой, согласованной со шкалой веса. Это важнее,
чем кажется: если считать «живописный» маршрут с эвристикой от «быстрого»,
поиск тихо вырождается в жадный и возвращает не тот маршрут, ничем не
сигнализируя об ошибке. В `test/router.test.mjs` это проверяется явно.

Профили: авто, велосипед, пешком, тропы. Учитываются односторонние,
паромы, платные участки, грунтовки, ступени, `sac_scale`, покрытие и штрафы
за повороты. Съехать с дороги, на которой вы уже стоите, можно всегда —
даже если включено «без платных».

## Радар камер

Предупреждает не «обо всём в радиусе», а о камере, к которой вы реально
подъезжаете:

* конус ±55° по курсу — камера на параллельной улице молчит;
* направление камеры: `camera:direction` читается как направление объектива
  (навстречу потоку), голый `direction` — как направление контролируемого
  потока;
* срабатывание по **времени** до камеры или по расстоянию — что наступит
  раньше. На 40 км/ч предупреждение приходит не позже, чем на 110;
* три стадии: 500 м / 250 м / 60 м, повтор не чаще раза в две минуты;
* **зоны средней скорости**: между парой камер считается фактическая средняя,
  и вы видите штраф до того, как он выписан, а не после;
* свои камеры добавляются вручную и переживают удаление региона.

Источник — OpenStreetMap. Это подсказка, а не замена дорожным знакам.

## Подсказки по полосам

Для онлайн-маршрутов OSRM отдаёт разметку полос на перекрёстке. Приложение
показывает её за 500 м до манёвра: непригодные полосы притушены, пригодные
белые, рекомендованная — зелёная. Если все полосы годятся, полоса подсказок не
показывается: она бы ничего не сообщала.

## Пробки

Живые пробки требуют коммерческого источника — бесплатного, легального и
актуального не существует. Поэтому слой опциональный: вставьте свой ключ
TomTom в настройках, и пробки появятся. Без ключа приложение не показывает
пробок вовсе — вместо того чтобы рисовать их из ниоткуда.

## Погода

Кроме обычного прогноза есть две вещи, которых нет ни у Google, ни у Apple:

* **дорожные условия** — гололёд, снегопад, аквапланирование, туман, боковой
  ветер. Отдельно ловится «окно чёрного льда»: чуть выше нуля, влажно;
* **погода по маршруту по времени прибытия** — каждая точка берётся на тот
  час, когда вы там окажетесь, а не на сейчас.

Последний прогноз сохраняется и показывается офлайн с пометкой «из кэша».

## Тропы

«Живописность» в OSM не размечена, поэтому она считается: видовые точки,
вершины, водопады и вода вдоль маршрута, извилистость, покрытие, маркировка,
`sac_scale`, наличие имени. Асфальтовая дорожка вдоль дороги получает 6 из 100,
размеченный горный маршрут с видовыми точками — 88.

Профиль высот подтягивается один раз онлайн и дальше живёт вместе с тропой.
Время хода — по правилу Нейсмита с поправкой на сложность.

## Тесты

```bash
node test/run.mjs          # маршрутизатор, радар, движок навигации

node serve.mjs 8099 &      # e2e в headless Chromium
PLAYWRIGHT_MODULE=/путь/к/playwright/index.mjs \
PW_CHROMIUM=/путь/к/chrome node test/e2e.mjs
```

E2E глушит все внешние хосты — то есть проверяет именно офлайн-пути:
приложение обязано загрузиться, построить маршрут, найти место и довести
до финиша, когда снаружи не отвечает ничто.

## Чего здесь честно нет

* **Пробок без своего ключа.** См. выше: с ключом TomTom слой работает, без
  ключа пробки не показываются.
* **Полос для офлайн-маршрутов.** Разметка полос приходит от OSRM, то есть
  только онлайн. В офлайн-графе её нет.
* **Дорожных знаков.** В OSM размечены слишком неровно, чтобы вести по ним.
* **Общественного транспорта.** Профиль зарезервирован, движка нет: бесплатного
  глобального маршрутизатора по расписаниям не существует.
* Камеры и тропы полны настолько, насколько полна OSM в вашем регионе.

## Структура

```
js/lib/       геометрия, IndexedDB, утилиты
js/core/      настройки и состояние
js/i18n/      ru/en (210 ключей, паритет проверяется)
js/map/       стили MapLibre и обёртка карты
js/offline/   Overpass, тайловый кэш, сборка пакетов регионов
js/routing/   граф, A*, манёвры, OSRM, единый сервис
js/nav/       движок ведения и голос
js/features/  камеры, погода, тропы, поиск, треки
js/ui/        шторка, HUD, панели, иконки
```

Лицензии данных — OpenStreetMap (ODbL), CARTO, Esri, OpenTopoMap, Open-Meteo,
RainViewer. Атрибуция показана на карте.
